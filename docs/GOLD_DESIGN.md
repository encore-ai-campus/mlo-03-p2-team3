# 50대 단승 취소 Gold 구현 명세

2026-11-20 (KST). 사용자 제공 팩트·차원 설명과 Gold 진행 요청을 구현 근거로 사용한다. 기존 Python/Parquet 파이프라인에서 clean을 읽어 스타 스키마를 생성한다. 참고 CSV 복사나 원천 재처리는 하지 않는다.

Parquet 스타 스키마와 감사 파일·사전·검증 JSON·SQL DDL/집계 예제를 생성한다. data/03_gold/에는 팩트1개·차원5개만 두고 감사3개는 meta/audit/에 저장한다. 데이터 파일명은 DIM_MEMBER.parquet·FCT_BET_SELECTION_CANCEL_50S.parquet 등 대문자, 확장자는 소문자로 통일한다. 논리 테이블명과 컬럼명은 유지한다. 승률구간 분석 보조 요약은 스타 스키마와 분리해 meta/WIN_RATE_CANCEL_SUMMARY.csv(UTF-8 BOM)에 둔다. DB 접속·적재는 범위 밖이다. 이전 평탄화 CSV를 재활용하면 현재 DQ 결정과 충돌하므로 채택하지 않는다. 현재 clean에서 재계산하는 방식을 선택했다.

분석은 생일 생성값·소매 재매핑 거래를 포함한 시뮬레이션의 연관성 탐색이며 실제 고객 행동·인과효과로 일반화하지 않는다.
