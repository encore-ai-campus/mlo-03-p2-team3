## 50대 단승 취소 팩트 관점과의 연결

| 설계 관점 | 품질 단계의 제공·보존 | Gold에서 남은 구현·검증 |
| --- | --- | --- |
| 원구매 전표 × 경주 × 단승 선택 말의 구매 선택 묶음 | 상세 행과 출처 보존 | 같은 선택을 합치고 업무키·팩트 PK 검증. 한 행을 실물 마권 1장으로 해석하지 않음 |
| 구매 당시 만 50~59세 | 전체 회원·거래 유지 | 생일과 원구매일로 만 나이 계산, 50대·WIN 조건 적용 |
| 구매 전 최근 1년 승률 | 말 스냅샷 원래 날짜·전적 보존 | 구매일보다 엄격히 이전인 스냅샷 사용, 분모 0과 0% 구분; 의료용 매칭을 그대로 말 개체 확정으로 쓰지 않음 |
| 확인된 고객 취소 | 원전표 미확인·불일치 표시, 원래 거래값 보존 | 회원·경주·승식·선택·수량/금액 검증; 취소 상세 순번을 원구매 순번으로 가정하지 않음; 불명확한 취소를 0으로 단정하지 않음 |
| 0원 제외 | 업무 집계 가능 플래그 제공, 오류 집계용 원본 유지 | 구매·취소 집계의 분자와 분모 모두에서 0원 제외 |
| 늦은 취소 포함 | D-004에 따라 유지·표시 | 참고 설계의 출발 전 취소 제한을 적용하지 않음. 늦은 취소도 연결 검증을 통과해야 확인 취소로 집계 |
| 말·경주·회원·날짜·채널 차원 | 입력 계약에 역할·키 합의 요구 기록 | 말 개체 검증, 공통 업무키·타입·코드 합의, 차원 PK 유일성·팩트 FK 존재·조인 전후 금액/행 수 대사 |
| 취소율과 분석 제한 | 공용 clean을 특정 팩트 조건으로 줄이지 않음 | 적격 구매 선택 묶음을 분모로 사용, 취소 전표를 분모에 더하지 않음. 금액 공식·분석 제외 사유는 담당자가 정의 |

참고 설계의 41,149행·적격 39,263행·확인 취소 875개는 이전 규칙의 예시 결과입니다. 현재 품질 결과의 Gold 기대값으로 확정하지 않았습니다. 생일 생성값·재매핑 시뮬레이션이라는 자료의 한계도 후속 분석에 명시해야 합니다.
