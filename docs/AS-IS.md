## 경주 매출 및 마권 발매 내역 현황

RC_SALES는 제주 경주의 전체 마권 매출을 경주·승식별로 집계한 자료다. BET_TICKET에는 전표별 마권 거래금액과 발매·취소·무효 상태가 기록되어 있다.

동일 경주의 단승 금액을 대조한 결과, 두 자료의 합계에 차이가 있었다. 본 프로젝트에서는 BET_TICKET을 발매 거래의 일부 범위를 담은 상세 자료로 간주하며, 경주 전체 매출은 RC_SALES를 기준으로 집계한다.

**자료 출처** · 발매 전표와 상세 내역(BET_ORDER, BET_TICKET)은 공개 거래 데이터를 마권 발매 시나리오에 맞춰 재구성했다. Chen, D. (2012). *Online Retail II*. UCI Machine Learning Repository, CC BY 4.0.

## 품질 관리에서 확인한 업무 문제

완전 중복을 제거한 뒤 측정한 결과입니다. 오류·불일치를 임의로 삭제하거나 수치 보정하지 않고, 근거가 있는 보정·제외와 분석용 표시를 구분했습니다.

| 결정 | 문제 | 실측 | 처리 |
| --- | --- | --- | --- |
| D-003 | 0원 마권 | 3,632행 | clean 유지·INVALID_YN=Y; 업무 집계 분자·분모 모두 제외, 오류 집계 포함 |
| D-004 | 취소시각 ≥ 경주 출발시각 | 1,000장 / 고유 546전표 | 마권·전표에 늦은 취소 표시, 취소 분석 포함. 0원 늦은 취소 교집합은 현재 0건 |
| D-005 | 마권 마명 빈값 | 1,560행 보정 | 출전표 키가 정확히 1행 연결될 때만 보정하고 원래 값·근거 기록 |

| D-006 | 유효 원전표에 연결되지 않는 취소 | 644전표 | ORIG_MISSING_YN 표시; 추정 재배정 금지 |
| D-007 | 진료 조 불일치 / 이전 스냅샷 미확인 | 11 / 71건 | 전체 진료 보존, 해당 조·스냅샷 분석에서 확인 필요 표시 |

## Gold 스타 스키마 도출
