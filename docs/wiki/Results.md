# 수행결과

### 단계별 행 수

실제 원천·Parquet 행 수입니다. 매출 분리·진료 브리지 확장이 있으므로 단계별 전체 행 수가 같아야 하는 것은 아닙니다.

| 데이터 | 원천 = Bronze | Silver 표준화 | Silver clean | 별도 제외 |
| --- | ---: | ---: | ---: | ---: |
| 전표 | 27,907 | 27,907 | 27,907 | 0 |
| 마권 | 523,416 | 523,416 | 522,364 | 1,052 |
| 회원 | 4,383 | 4,383 | 4,383 | 0 |
| 말 주간 스냅샷 | 52,642 | 52,642 | 52,642 | 0 |
| 조교사 주간 스냅샷 | 954 | 954 | 954 | 0 |
| 경주 | 386 | 386 | 386 | 0 |
| 출전 | 3,666 | 3,666 | 3,666 | 0 |
| 배당·구간 기록 | 3,666 | 3,666 | 3,666 | 0 |
| 결과 | 3,666 | 3,666 | 3,666 | 0 |
| 승식별 매출 + 경주 합계 | 3,088 | 2,702 + 386 | 2,702 + 386 | 0 |
| 진료 기록 | 1,488 | 1,488 | 1,488 | 0 |
| 진료 유형 브리지 | 진료명 항목에서 파생 | 1,664 | 1,662 | 0; 유형 통합으로 2행 감소 |
| 변경 공지 | 149 | 149 | 149 | 0 |
| **물리적 행 수 합계** | **625,411** | **627,075** | **626,021** | **1,052** |

전체 변화는 `625,411 + 브리지 1,664 = 627,075`, `627,075 − 중복 1,052 − 브리지 통합 감소 2 = 626,021`입니다. 브리지 통합은 진료 2건의 잘못 분리된 유형을 다시 묶은 것으로, 진료 기록 삭제가 아닙니다(D-011).

원천·표준화·중복 제거 후 수치는 기준이 다릅니다. 정의와 전체 결과는 [품질관리 보고서](../품질관리.md)를 참고합니다. 규칙 간 대상이 겹치므로 건수를 합산해 고유 오류 행 수로 해석하지 않습니다.

### Gold 대사 결과

| 주제 | 검증·집계 | 실제 결과 |
| --- | --- | ---: |
| 출전 | clean 출전 = 팩트 | 3,666 = 3,666행 |
| 출전 | 출주 / 우승 / 3착 이내 합계 | 3,644 / 386 / 1,158 |
| 진료 | clean 진료 = 팩트 = `SUM(VET_CNT)` | 1,488 |
| 진료 | clean 유형 연결 = Gold 브리지 | 1,662 = 1,662행 |
| 매출 | clean 마권 = 팩트, Gold 입력 제외 | 522,364 = 522,364행 / 제외 0 |
| 매출 | 정상 발매액 / 판매 마권 장수 | 1,903,091,700원 / 507,383장 |
| 매출 | 취소액 / 무효액 | 41,064,800원 / 8,192,700원 |
| 매출 | 취소 차감 후 금액 | 1,862,026,900원 |
| 취소 | 대상 구매 상세 → 구매 묶음 | 61,430행 → 41,141행 |
| 취소 | 전체 묶음 = 적격 + 분석 제외 | 41,141 = 39,284 + 1,857행 |
| 취소 | 적격 구매 중 확인 취소가 있는 묶음 | 894 |
| 취소 | 전체 구매 금액 / 전체 검증 통과 취소 금액 | 241,761,600원 / 4,274,800원 |
| 공통 | Gold 테이블별 PK 중복·NULL / 팩트·브리지 FK 누락 | 각각 0건 |

취소 분석 제외 1,857행은 `ANALYSIS_ELIGIBLE_YN=N`과 사유를 가진 채 팩트에 보존됩니다. 전체 구매·취소 금액과 적격 39,284묶음의 분석 범위를 구분해야 합니다.

FK 누락 0건은 업무 속성이 모두 알려져 있다는 뜻은 아닙니다. 진료 71행의 말, 매출 308행의 채널은 실제 차원에 존재하는 **미상 키 0**을 참조합니다. 취소일이 없는 취소 팩트 40,187행도 날짜 키 0을 사용합니다.

취소 피처는 Gold 전체 기간 취소 합계와 범위가 다릅니다. 원구매 연결 후보도 출발 전 판매로 제한하고, 출발 이후의 거래가 피처 판정을 바꾸지 않도록 합니다. 최종 배당은 비교용 기준선으로만 사용합니다.

상세 피처·관측 시점 가정은 [AI Ready 문서](../ai_ready.md)를 참고합니다.
