# AI Ready Data: 출전마 3등 이내 예측

- **코드:** `src/ai_ready/05_ai_ready.py` (생성), `src/ai_ready/05_ai_ready_check.py` (검증)
- **입력:** Gold 팩트 4개와 공통 차원 (`data/03_gold/`). 은빈 님 취소 피처만 clean 전표·마권(`data/02_silver/clean/`, D-012)을 함께 씁니다
- **출력:** `data/04_ai_ready/`

| 파일 | 내용 |
|:--|:--|
| `AI_READY_RACE_ENTRY.parquet` | 사람이 읽는 피처 테이블 (범주형은 코드값 그대로, NULL 있음) |
| `AI_READY_RACE_ENTRY_ENCODED.parquet` | 모델 입력용. 범주형 원-핫, Y/N은 1/0, NULL은 0 + `_NA` 표시 컬럼 |
| `_excluded/AI_READY_RACE_ENTRY.parquet` | 제외한 22행과 사유 |

## 1. 무엇을 예측하나

경주 출발 전에 알 수 있는 정보로 **이 말이 3등 안에 들까?**를 예측합니다.

- **행 단위:** 실제로 출주한 말 1두 (`RACE_KEY` + `CHUL_NO`), 3,644행
- **제외:** 경주제외(94)·출주취소(95)로 뛰지 않은 22행은 정답이 없어서 `_excluded/`에 보존합니다 (3,644 + 22 = 출전표 3,666)
- **정답:** `PLACE_YN` = 착순 3 이내면 1. 비율 31.8%
- **예측 시점:** 경주 출발 시각 `START_DTM`. 이 시각 이후에 생기거나 알게 되는 정보는 피처에 넣지 않습니다
- **분할:** `SPLIT_CD`. 경주일 2026-10-09까지 `TRAIN` 2,895행, 2026-10-10부터 `TEST` 749행. 무작위로 섞지 않습니다

### 원주 (race_entry)

| 피처 | 뜻 | 계산 |
|:--|:--|:--|
| `HR_AGE`, `HR_SEX_CD`, `HR_GRADE_CD` | 말 나이·성별·등급 | 출전 팩트가 가리키는 경주일 기준 말 버전 (`DIM_HORSE` SCD2) |
| `TRAINER_KEY` | 조교사 | 출전 팩트 값 그대로 |
| `RC_DIST_M`, `RC_GRADE_CD`, `WEATHER_CD`, `TRACK_STAT_CD` | 거리, 경주 등급, 날씨, 주로 상태 | `DIM_RACE` |
| `FIELD_CNT` | 출전 두수 | 경주별 출전표 행 수 |
| `PRIOR_START_CNT`, `PRIOR_WIN_CNT`, `PRIOR_PLACE_CNT` | 이전 출주·1착·3착 이내 수 | 같은 말(`HR_NM`)의 이번 경주일 **이전** 경주만. 같은 날 경주는 넣지 않음 |
| `PRIOR_PLACE_RATE` | 이전 3착 이내 비율 | `PRIOR_PLACE_CNT ÷ PRIOR_START_CNT`. 이전 출주가 없으면 NULL (830행) |
| `DAYS_SINCE_LAST_RACE` | 직전 출주 후 지난 일수 | 이전 출주가 없으면 NULL |

### 세은 (horse_medical)

말은 `HORSE_KEY`가 아니라 `HR_NM`으로 연결합니다. `HORSE_KEY`는 SCD2 버전마다 달라서 같은 말의 과거 진료가 빠지기 때문입니다. 진료일과 보고일이 **모두** 경주일 이전인 진료만 씁니다. 진료보다 늦게 보고된 기록이 많아서, 진료일만 보면 예측 시점에 몰랐던 진료가 들어갈 수 있습니다.

| 피처 | 뜻 | 계산 |
|:--|:--|:--|
| `VET_CNT_30D` | 경주 전 30일 진료 횟수 | 경주일 − 30일 ≤ 진료일 < 경주일, 보고일 < 경주일. 없으면 0 |
| `VET_CNT_90D` | 경주 전 90일 진료 횟수 | 같은 조건, 90일 |
| `LAMENESS_90D_YN` | 최근 90일 파행 진료 여부 | 90일 조건의 진료 중 유형 이름에 '파행'이 들어간 유형(기타 파행, 좌전지파행 등 8개)이 하나라도 있으면 Y |

진료 횟수는 유형 브리지를 붙이기 전에 팩트에서 셉니다. 유형이 여러 개인 진료가 두 번 세어지지 않게 하기 위해서입니다. 이전 스냅샷이 없어 말 키가 0인 진료 71건은 Gold만으로는 말을 특정할 수 없어 쓰지 않습니다. 진료 데이터는 5월 16일부터 있으므로, 초반 경주의 0은 "관측된 진료 0건"이라는 뜻입니다.

### 희정 (race_sales)

공통 조건: `SALE_DTM < START_DTM`, `INVALID_YN = 'N'`, `TICKET_STAT_CD`는 `SOLD`·`CANCEL`만. 판매와 취소 모두 자기 전표의 `SALE_DTM`으로 시간 조건을 적용하고, 경주별 1행으로 집계해 `RACE_KEY`로 붙입니다.

| 피처 | 뜻 | 계산 |
|:--|:--|:--|
| `SALES_AMT` | 출발 전 정상 발매액(원), 취소 차감 전 | `SUM(BET_AMT)`, SOLD |
| `SOLD_TICKET_CNT` | 출발 전 정상 발매 마권 수(장) | `COUNT(*)`, SOLD |
| `CANCEL_AMT` | 출발 전 취소액(원, 양수) | `SUM(-BET_AMT)`, CANCEL |
| `CANCEL_RATE` | 금액 기준 취소율 | `CANCEL_AMT ÷ SALES_AMT`, 분모 0이면 NULL |
| `AVG_TICKET_AMT` | 정상 발매 마권당 평균 금액(원) | `SALES_AMT ÷ SOLD_TICKET_CNT`, 분모 0이면 NULL |

VOID는 무효가 확정된 시각을 알 수 없어서 쓰지 않습니다.

### 은빈 (bet_cancel)

Gold 취소 팩트의 취소 금액에는 출발 후 취소까지 합쳐져 있습니다. 그래서 출발 전 취소만 보려고 clean 전표·마권의 거래 시각으로 다시 집계합니다. 경주 + 출전 번호별 1행으로 붙입니다.

| 피처 | 뜻 | 계산 |
|:--|:--|:--|
| `WIN_50S_PURCHASE_GROUP_CNT` | 출발 전 50대 단승 구매 묶음 수 | `COUNT(DISTINCT ORDER_NO)` |
| `WIN_50S_PURCHASE_AMT` | 출발 전 50대 단승 구매 금액(원), 취소 차감 전 | `SUM(BET_AMT)` |
| `WIN_50S_CANCEL_GROUP_CNT` | 출발 전 확인 취소가 있는 구매 묶음 수 | `COUNT(DISTINCT ORIG_ORDER_NO)`. 같은 구매를 여러 번 취소해도 1건 |
| `WIN_50S_CANCEL_AMT` | 출발 전 확인 취소 금액(원) | `SUM(ABS(BET_AMT))`. 나눠서 취소한 금액은 합산 |
| `WIN_50S_CANCEL_AMT_RATE` | 출발 전 금액 취소율 | 취소 금액 ÷ 구매 금액, 구매가 없으면 NULL (15행) |

- **구매:** SALE 전표, 구매 당시 만 50~59세 회원, 단승(`WIN`), `SALE_DTM < START_DTM`. 0원 마권과 VOID는 제외합니다
- **취소:** CANCEL 전표의 단승 마권이고, `ORIG_ORDER_NO`가 대상 구매를 가리키며 회원·경주·출전 번호가 같아야 합니다. 원구매 시각 ≤ 취소 시각 < 출발 시각이어야 하고, 0원·VOID는 제외합니다. "검증 통과 취소"는 Gold 취소 팩트가 `VERIFIED_CANCEL`로 판정한 구매 묶음만 셉니다. 취소액이 구매액보다 크거나 연결이 불확실한 묶음은 `AMBIGUOUS`라서 빠집니다
- 해당 말에 구매·취소가 없으면 건수와 금액은 0입니다

## 4. 평가 방법 (팀 합의)

성능은 통과·실패 기준이 아니라 비교용 숫자입니다. 경주마다 확률이 높은 3두를 "3등 이내"로 찍으면 정밀도와 재현율이 같은 값이 됩니다.

| 방법 | TEST 정밀도 = 재현율 | AUC |
|:--|--:|--:|
| 그냥 찍기 | 30.8% (TEST 정답 비율) | 0.50 |
| 배당 순위 (`BASE_EXPECT_WIN` 상위 3두) | 52.4% | 0.749 |

모델 학습은 아직 진행하지 않았습니다(대기). 진행하면 ① 원주 피처 → ② + 진료 → ③ + 매출·취소 순서로 비교해서, 정제한 데이터를 붙일 때 얼마나 좋아지는지 봅니다. 정확도는 3등 밖인 말이 많아서 저절로 높게 나오므로 참고용으로만 씁니다.

## 6. 한계

- 배당은 최종 배당이라 관측 시각을 모릅니다. 그래서 피처에 넣지 않고 기준선으로만 씁니다.
- 날씨·주로 상태는 경주 당일 발표값입니다. 출발 전에 공개된다고 보고 피처에 넣었습니다.
- 은빈 님 피처는 50대 회원의 단승만 담습니다. 전체 고객 성향이 아니라 "50대 단승 구매 성향"입니다.
- 원-핫 값 목록은 전체 기간의 값으로 만듭니다. 값 자체는 출발 전 공개 정보라 누수는 아닙니다. 지금 데이터에는 TRAIN에서 전부 0인 원-핫 컬럼이 없습니다.
