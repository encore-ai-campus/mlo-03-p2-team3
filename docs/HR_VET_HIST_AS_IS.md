# 진료 이력 AS-IS 데이터 프로파일링

팀 공용 원천 `data/00_origin/horse/HR_VET_HIST.csv`는 UTF-8-SIG CSV다. 헤더를 제외하면 1,488행과 6개 컬럼이다. 진료일은 2026-05-16~2026-11-18, 보고일은 2026-05-20~2026-11-18이다.

## 원천에서 확인한 내용

| 원천 컬럼 | 고유값 수 | 결측 건수 | 관측 내용 |
|---|---:|---:|---|
| `VET_DT_RAW` | 84 | 0 | 진료일이 `YYYY.MM.DD` 문자열로 제공된다 |
| `HR_NAME` | 569 | 0 | 마명만 있고 개체 식별 번호가 없다 |
| `TR_GRP_NO` | 18 | 0 | 앞자리가 0인 조 번호가 667행에 있다 |
| `VET_PLACE_NM` | 1 | 0 | 전 행의 값이 `KRA 제주경마`다 |
| `VET_NM_RAW` | 78 | 0 | 복수 진료명이 한 셀에 담긴 행이 176개다 |
| `REPORT_DT` | 27 | 0 | 보고일이 `YYYYMMDD` 문자열로 제공된다 |

빈 문자열, 공백만 있는 값, 하이픈으로만 된 값을 결측으로 집계했다. 완전히 동일한 중복행, 날짜 파싱 실패, 진료일이 보고일보다 늦은 행은 모두 0건이었다.

진료명 `정치,낭치`는 119행에 나온다. 해석이 모호한 `일,열사병`은 2행에 나오며, Silver에서는 팀 분리 규칙을 적용하고 전체 문구를 진료 이력에 남겼다.

## Bronze·Silver 검증 결과

| 단계 | 검증 결과 |
|---|---|
| Bronze | 1,488행이며, 원천 6개 컬럼의 이름·순서·셀 값이 일치한다. 추적용 컬럼 4개를 추가했다 |
| Silver 진료 이력 | 1,488행이며, 표준 컬럼 7개와 `_SRC_ROW_NO`를 저장한다. 날짜 2개를 `DATE`로 통일하고 조 번호의 앞자리 0을 보존했다 |
| Silver 진료 유형 브리지 | 복수 진료명 176행을 포함한 전체 이력에서 1,664개 진료명 항목을 추출해 `VET_SEQ`로 연결했다 |

파일별 입력·출력과 컬럼별 변환은 [진료 이력 데이터 사전](../meta/HR_VET_HIST_DATA_DICTIONARY.md)에 기록했다.
