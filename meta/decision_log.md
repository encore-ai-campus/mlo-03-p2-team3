# 결정 로그

품질 규칙과 처리의 근거입니다. 규칙(`DQ-…`)은 반드시 아래 ID 중 하나를 근거로 가집니다 (D-009).

## 팀 결정 (팀 최종 기준 "표준화 · 품질 관리 진행 기준")

| 결정 ID | 내용 |
|:--|:--|
| D-001 | 처리 순서: 완전 중복 제거 → 나머지 규칙 측정 → 집계별 제외 조건 적용. 나머지 규칙은 모두 완전 중복을 제거한 뒤 측정한다 |
| D-002 | 마권 완전 중복: 추적 컬럼(`_SRC_*`)을 뺀 업무값으로 판단. `_SRC_ROW_NO` 최소 행만 남기고(동률이면 Bronze 경로 오름차순) 나머지는 `_excluded/`에 근거와 함께 보관 |
| D-003 | 0원 마권: 삭제하지 않고 `INVALID_YN = Y`로 `clean/`에 보관. 매출·취소율의 분자·분모에서 제외, 오류 집계에는 포함 |
| D-004 | 늦은 취소: 취소 시각 ≥ 그 마권 경주의 출발 시각이면 마권 `LATE_CANCEL_YN = Y`, 전표는 하나라도 해당하면 Y. 삭제하지 않고 취소 분석에 포함. 0원 늦은 취소는 따로 표시. 전표 지표는 고유 전표 수로 집계 |
| D-005 | 마권 마명 빈칸: 경주일 + 경주번호 + 마번으로 출전표 정확히 한 행에 연결될 때만 보정. 원래 값, 보정 근거, `HR_NM_FILLED_YN` 기록 |
| D-006 | 전표·마권 장수·금액 불일치는 `HEADER_MISMATCH_YN`, 원전표 없는 취소는 `ORIG_MISSING_YN`. 금액·장수·원전표 연결은 고치지 않음 |
| D-007 | 진료 조 불일치·이전 스냅샷 없음: `clean/`에 보존. 전체 진료 건수에 포함, 조·스냅샷 기준 분석에서는 확인 필요로 표시. 담당자 결정 전까지 보정·제외하지 않음 |
| D-008 | 저장: 표준화 결과(`data/02_silver/*.parquet`)는 그대로 보존. 유지 행(플래그 행 포함)은 `clean/`, 제외 행은 `_excluded/`. 테이블별 표준화 행 수 = clean + _excluded 대사. 진료명 브리지는 따로 대사 |
| D-009 | ID 형식: 규칙 `DQ-{차원}{번호}`(U 유일성, C 완전성, V 유효성, S 일관성, R 참조, T 시점), 결정 `D-nnn`. 모든 처리 행에 규칙 ID, 결정 ID, Bronze 상대 경로, `_SRC_ROW_NO`를 남김 |
| D-010 | 코드는 각자 쓰고 규칙·기준 숫자를 맞춘다. 각자 스타 스키마까지 만든 뒤 Silver와 공통 차원을 하나로 합친다 |
| D-011 | 진료명 `일,열사병`(원천 595·664번): 원문 보존, 유형별 집계에서는 `일·열사병` 한 유형으로 진료 1건당 한 번 |
| D-012 | Gold 입력: 4명 모두 같은 버전의 `data/02_silver/clean/`만 사용 |

## Gold 공통 차원 결정 (2026-11-23 팀 합의, `data/03_gold/common/`)

| 결정 ID | 내용 |
|:--|:--|
| D-013 | 공통 차원 키·이름: 대리키는 업무 키로 정렬한 순번(1부터)이라 같은 clean이면 항상 같다. 원천이 바뀌면 공통 차원과 팩트를 함께 재생성. 미상 행은 모든 차원에서 키 0, 이름 `UNKNOWN`, 나머지 NULL. 날짜 키는 YYYYMMDD 정수. 컬럼 이름은 대문자, 시각은 시간대 없는 KST |
| D-014 | 공통 차원 범위: 팩트에 나온 값만이 아니라 clean 전체(채널은 장외 지점 전부). `DIM_DATE`는 팩트가 참조하는 clean 날짜(경주일·진료일·보고일·스냅샷일·판매일)의 최소~최대 연속 범위(2026-05-16 ~ 2026-11-18) + `RACE_DAY_YN`. 날짜 역할(구매일·취소일 등)은 같은 차원을 쓰고 FK 이름으로 구분 |
| D-015 | `DIM_HORSE`는 SCD2. 스냅샷 다음 날부터 유효하고, 연결 조건은 `VALID_FROM_DT ≤ 기준일 ≤ VALID_TO_DT`. 기준일은 경주는 경주일, 진료는 진료일, 취소 분석은 원구매일. 맞는 버전이 없으면 `HORSE_KEY = 0`. `DIM_TRAINER`는 기존 18행·키 유지 + 미상 행 |
| D-016 | `DIM_MEMBER`: 회원 4,383명(키 1~4,383) + `NON_MEMBER`(회원번호 빈칸 = 실제 비회원, 별도 양수 키) + `UNKNOWN`(키 0, 미확인). 비회원은 전표 4,921건 기준(마권으로는 106,647행). 회원번호가 있는데 회원 마스터에 없는 전표는 0건 |
| D-017 | Gold 이름: Silver에서 가져온 컬럼은 이름 유지, 새 컬럼은 매핑 규칙서 2장 주제어·접미사, 대리키 `차원이름_KEY`, 역할 날짜 키 `역할_DT_KEY`(경주일은 `DATE_KEY`), 여부 `_YN`(Y/N). 규칙서 13장, 검사 `04_gold_naming_check.py` |
